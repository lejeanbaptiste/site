## Droits de propriété intellectuelle

Le site est soumis à la législation française et internationale sur le droit d’auteur et la propriété intellectuelle. Tout exemple littéraire utilisé sur le site peut être reproduit selon les normes applicables de reproduction des œuvres littéraires, à condition que la source et l’auteur soient cités.

Sauf indication contraire, le code source de Grognard est distribué sous licence [GNU General Public License version 2.0](https://www.gnu.org/licenses/old-licenses/gpl-2.0.html). Les composants et ressources tiers conservent leurs propres licences ; leur liste est disponible dans le fichier [THIRD_PARTY_NOTICES.md](https://github.com/lejeanbaptiste/lejeanbaptiste/blob/main/THIRD_PARTY_NOTICES.md).

## Droits de reproduction

Le contenu éditorial de ce site ne peut être reproduit sous quelque forme que ce soit sans l’autorisation préalable de son auteur ou des ayants droit concernés. Toute copie, totale ou partielle, des textes du site est susceptible de constituer une contrefaçon au regard des dispositions du Code de la propriété intellectuelle français.

## Données et logiciels tiers

Grognard peut utiliser des données structurées et des ressources lexicales ou d’autorité provenant de sources externes. Ces données restent soumises aux licences et conditions de réutilisation de leurs projets respectifs. Les informations de provenance et les licences applicables sont documentées dans le logiciel et dans les dépôts concernés.

Grognard fonctionne d’abord avec les fichiers locaux de l’utilisateur. Les textes édités restent dans le projet local, sous le contrôle de l’utilisateur, sauf lorsqu’une fonction explicitement connectée — par exemple une recherche d’autorité ou une importation en ligne — est utilisée.

## Crédits

Grognard est un fork de bureau de [LEAF-Writer](https://leaf-writer.leaf-vre.org/), lui-même issu de CWRC-Writer. Le projet remercie les équipes et communautés qui maintiennent ces logiciels ainsi que les bibliothèques incluses dans la distribution.

Le code source, les versions publiées et le suivi du projet sont disponibles sur [GitHub](https://github.com/lejeanbaptiste/lejeanbaptiste).
